# Данные кейса

Материалы организаторов в репозиторий не входят. Перед запуском положите сюда:

| Файл | Что это |
|---|---|
| `kb.zip` | база знаний (законы и документы организации) |
| `questions.csv` | вопросы для сабмита (`id,question`) |
| `demo_reference.csv` | демо-вопросы с эталонными ответами (нужны только для оценки) |

Набор `eval/datasets/demo.jsonl` для оценки строится из `demo_reference.csv`: `python eval/build_demo.py`.

Индекс базы (`artifacts/index`) строится автоматически при первом запуске и сохраняется для следующих.
