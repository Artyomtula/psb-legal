# ПСБ · Юридический ассистент

ИИ-ассистент для юристов банка. Отвечает на вопросы по базе нормативных актов и внутренних документов, ссылается на конкретные пункты и статьи, учитывает редакции документов на дату события и отказывается отвечать, если в базе нет данных.

Ниже — как запустить его на своём компьютере. Скрипт запуска сам проверит Docker, спросит API-ключ, соберёт и запустит приложение и откроет чат в браузере.

## Что понадобится

- **Docker Desktop**: [скачать для Windows и macOS](https://www.docker.com/products/docker-desktop/). На Windows нужен WSL 2, установщик Docker предложит его включить. Docker нужно не меньше 8 ГБ оперативной памяти: на компьютере с 16 ГБ так настроено по умолчанию, на компьютере с 8 ГБ лимит придётся поднять (см. раздел «Если что-то пошло не так»).
- **Около 12 ГБ свободного места** на диске и интернет на время первой сборки.
- **API-ключ DeepSeek** с положительным балансом ([platform.deepseek.com](https://platform.deepseek.com) → API keys).
- **Архив базы знаний `kb.zip`** из материалов кейса. В репозиторий он не входит.

Сам проект скачайте со страницы репозитория: **Code → Download ZIP**, затем распакуйте архив. Можно и через `git clone`.

## Запуск на macOS

1. Запустите Docker Desktop и дождитесь, пока он загрузится (значок кита в строке меню перестанет мигать).
2. Положите `kb.zip` в папку `data` внутри проекта. Можно пропустить: скрипт сам попросит указать файл.
3. Откройте **Терминал**, наберите `cd `, перетащите в окно папку проекта и нажмите Enter.
4. Запустите скрипт:

   ```bash
   bash start.sh
   ```

5. Вставьте API-ключ (`Cmd+V`) и нажмите Enter. Символы ключа на экране не отображаются, это нормально. Скрипт проверит ключ и баланс.
6. Дождитесь сообщения «Готово». Чат откроется в браузере сам.

## Запуск на Windows

1. Запустите Docker Desktop и дождитесь статуса **Engine running** в левом нижнем углу его окна.
2. Положите `kb.zip` в папку `data` внутри проекта. Можно пропустить: скрипт сам попросит указать файл.
3. Дважды щёлкните `start.bat` в папке проекта. Если Windows предупредит о файле из интернета, подтвердите запуск.
4. Вставьте API-ключ (`Ctrl+V` или правый щелчок мыши) и нажмите Enter. Символы ключа на экране не отображаются, это нормально. Скрипт проверит ключ и баланс.
5. Дождитесь сообщения «Готово». Чат откроется в браузере сам.

Если `start.bat` не запускается, откройте PowerShell в папке проекта и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

## Что происходит при первом запуске

| Этап | Время |
|---|---|
| Сборка образов: зависимости, модели поиска bge-m3 и bge-reranker-v2-m3 (~4,5 ГБ), интерфейс | 10–20 минут, зависит от скорости интернета |
| Построение индекса базы знаний при первом старте | 1–3 минуты |
| Повторные запуски | около минуты |

Если сборка оборвётся из-за сети, скрипт сам повторит её до четырёх раз. Уже собранные шаги при этом не повторяются.

Ключ сохраняется в файле `.env` в папке проекта и никуда не отправляется, кроме API языковой модели. При повторном запуске скрипт предложит оставить сохранённый ключ: достаточно нажать Enter.

## Как проверить

После запуска откроются:

- **чат с ассистентом**: http://localhost:3000;
- **документы базы знаний**: http://localhost:8000/kb.

Если порт 3000 или 8000 уже занят другой программой, скрипт возьмёт следующий свободный (3001, 8001 и т. д.) и выведет итоговые адреса.

Вопросы для проверки:

1. «Какая арендная плата по договору с ООО «Северный Склад» и до какого числа её нужно вносить?» В ответе будут ссылки на пункты договора. Клик по ссылке открывает документ с подсвеченным пунктом, а карточки источников под ответом показывают текст фрагментов.
2. «Договор на 12 млн рублей заключали в августе 2024 года. Нужно ли было одобрение генерального директора?» Ассистент берёт редакцию документа, действовавшую на дату события.
3. «Почему арендная плата 500 000 рублей?» Ассистент находит ошибку в вопросе.
4. «Какой размер пособия по беременности и родам?» Этого нет в базе, ассистент так и ответит.
5. «Какой срок оплаты по договору с «Альфой»?» Контрагент назван неоднозначно, ассистент разберёт оба договора.

Блок «Размышления» над ответом показывает ход работы: какие документы выбраны, какие положения отобраны, что нашла проверка.

## Остановка и повторный запуск

Все команды выполняются в папке проекта: в Терминале на macOS, в PowerShell или командной строке на Windows.

| Действие | Команда |
|---|---|
| Остановить | `docker compose down` |
| Запустить снова | `bash start.sh` (macOS) или `start.bat` (Windows) |
| Посмотреть журнал ассистента | `docker compose logs -f legal-api` |
| Удалить всё, включая образы, индекс и историю чатов | `docker compose down -v --rmi all` |

После перезагрузки компьютера приложение само не запускается. Запустите скрипт ещё раз.

## Если что-то пошло не так

| Сообщение или симптом | Что сделать |
|---|---|
| «Docker не найден» | Установите Docker Desktop и запустите скрипт снова. |
| «Docker не отвечает» | Откройте Docker Desktop, дождитесь окончания загрузки и повторите. |
| «API отклонил ключ» | Скопируйте ключ ещё раз целиком и вставьте заново. |
| «На балансе DeepSeek нет средств» | Пополните баланс на platform.deepseek.com. |
| «Ассистент не запустился», в журнале `Killed` или код 137 | Docker не хватает памяти. macOS: Docker Desktop → Settings → Resources → Memory, поставьте 8 ГБ. Windows: в файле `%UserProfile%\.wslconfig` задайте `memory=8GB` в разделе `[wsl2]` и перезапустите Docker Desktop. |
| Сборка падает с ошибкой сети | Запустите скрипт ещё раз: уже собранные шаги повторно не выполняются. |
| Ответ не приходит или приходит ошибка | Посмотрите журнал: `docker compose logs --tail 100 legal-api`. |

## Запуск без скрипта

Создайте в папке проекта файл `.env`:

```
LLM_API_KEY=ваш_ключ
```

Затем выполните:

```bash
docker compose up -d --build
```

Чат будет доступен на http://localhost:3000, когда команда `docker compose ps` покажет оба контейнера запущенными, а `legal-api` — в состоянии `healthy`.

Чтобы подключить другой OpenAI-совместимый API вместо DeepSeek, добавьте в `.env` строки `LLM_BASE_URL=` и `LLM_MODEL=` до запуска скрипта.
